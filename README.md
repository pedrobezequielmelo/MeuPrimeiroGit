Este projeto foi desenvolvido durante o laboratório prático de Git.

Projeto desenvolvido para praticar Git e GitHub.

## Questionário

1. Qual é a diferença entre Working Directory, Staging Area e Repository?

Working Directory seria aonde ficam os carquivos de trabalho
Staging Area é onde colocamos as alteraçoes e atualizacoes do commit
Repository é aonde fica registrado todo o historico

2. Qual é a diferença entre git commit e git push?

O git commit registra as alterações no histórico local do projeto
O git push envia os commits do repositório local para o repositório no github

3. É possível realizar vários commits antes de executar um git push? Explique.

Sim podemos realizar vários commits localmente e depois executar um único git push para enviar ao github

4. Por que é interessante realizar commits pequenos e descritivos?

Porque facilita a organização e a compreensao do histórico do projeto

5. O que acontece com os commits locais quando ainda não executamos o git push?

Eles permanecem no repositório da maquina

6. Como verificar, pelo GitHub, se os commits foram enviados corretamente?

Podemos acessar o repositório no GitHub e verificar o histórico de commits para confirmar se as alterações foram enviadas
